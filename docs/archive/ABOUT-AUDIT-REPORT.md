# About / Story Page — Full Audit & Remediation Report

**Project:** Abhijeet Varghese / AV OS
**Version:** v2.4.20
**Audit date:** 2026-08-16
**Audited surface:** About page, shared navigation/footer, publishing renderer, design source, template and generated output

## Result

**PASS — audited, remediated, republished and regression-tested.**

The About page remains the approved cinematic eight-card experience, but its layout and motion implementation is now more robust across compact phones, short landscape screens, tablets, desktops, ultrawide displays and 4K/5K resolutions.

## Issues found and fixed

### Layout and responsive behaviour

1. **Malformed global CSS** — an orphaned Serif declaration block left the main stylesheet with an unmatched closing brace. Removed; all three runtime stylesheets now have balanced braces.
2. **Sticky 3D stage was not truly sticky through the runway** — `body { overflow-x: hidden }` created a vertical scroll container as a CSS side effect. Replaced with `overflow-x: clip`, preserving horizontal containment without changing the scroll root.
3. **Transformed layers increased document width** — added root-level paint clipping. Horizontal overflow is now zero while preserving the intended edge-bleeding portrait and cinematic transforms.
4. **Card 01 advanced before the sticky stage arrived** — progress was measured from the full section, including its editorial header. It is now measured from `.about-evo3d__scroll`, so the first card is perfectly settled at stage entry.
5. **Compact landscape glass plate could cross the card edge** — added a dedicated ≤768px / ≤480px landscape composition with a taller world, tighter type and reduced internal spacing.
6. **Compass jumps could stop one card early** — exact integer targets combined with asymptotic lerping. Added a small post-boundary bias so direct navigation resolves to the requested card.

### Motion and performance

7. **3D interpolation was frame-rate dependent** — fixed-factor per-frame lerping made high-resolution/low-fps displays lag behind. Replaced with time-based exponential damping, producing consistent choreography at different refresh rates and rendering loads.
8. **Animation loops ran while offscreen** — the 3D renderer now sleeps when the runway is outside the viewport or the document is hidden, and resumes without a catch-up jump.
9. **Pointer camera used a second continuous animation loop** — merged into the stack’s single gated loop. Coarse-pointer/touch devices retain a stable camera.
10. **Reduced motion** — confirmed all eight cards become static, sequential and readable with no hidden reveal content.

### Accessibility and navigation

11. **Mobile menu lacked modal focus management** — now uses `role="dialog"`, `aria-modal="true"`, a keyboard focus trap, Escape close and focus return.
12. **Case Studies and Portfolio shared a destination and both received `aria-current`** — renderer now exposes only one current-page link to assistive technology.
13. **Portfolio persistence** — verified in desktop navigation, mobile navigation and footer on all 24 generated HTML pages, in the canonical seed and in MySQL. Portfolio and Case Studies now have separate URLs and layouts.
14. **Native cursor requirement** — removed all remaining inert `data-cur` attributes. No cursor overlays, `cursor:none`, contextual cursor labels or cursor-following code remain in runtime files.
15. **Pondar removal** — no runtime Pondar references remain. Fonts are Inter Tight, Instrument Serif and Poppins.

### Source and publishing integrity

16. Latest About markup is generated by `PublishEngine.php`; CMS publishing no longer reverts the page.
17. Frontend source, `site-template` assets and generated public output were synchronised.
18. `abhijeetvarghese/` and `avos-php/public_html/site/` are byte-identical after the final publish.
19. The page-specific design-system document and project handover were updated to match the implemented state.
