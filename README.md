# AV OS — Abhijeet Varghese Creative Portfolio

Source repository. The deployable artifact is generated by CI onto the
`hostinger` branch — never hand-edited.

| Path | Purpose |
|---|---|
| `frontend/` | Public site — React 19 + TypeScript + Vite, static SSG, clean URLs |
| `admin/` | AV OS admin (React SPA) served at `/os/` |
| `avos-php/` | Bespoke PHP 8 backend, MariaDB, shared-hosting compatible |
| `avos-data/` | Canonical content seeds |
| `tools/` | Engineering instruments (retirement evidence, identity leak guard) |
| `docs/` | Architecture, runbooks and phase reports |
| `tests/` | QA and acceptance suites |

## Key documents

- `docs/BACKEND-RETIREMENT-PLAN.md` — evidence-based legacy retirement
- `docs/HOSTINGER-PRIVATE-CONFIG-RUNBOOK.md` — private configuration outside the web root
- `docs/DEPLOY-HOSTINGER-PHP.md` — deployment guide

## Engineering tools

```bash
python3 tools/retirement-evidence.py .            # what is safe to delete, and why
AV_OWNER_EMAIL=… python3 tools/identity-leak-guard.py frontend/dist admin/dist
```

## Rules

- Public URLs carry no file extension (`§103` gate enforces this in CI).
- The private owner email must never appear in a client artifact.
- `config.local.php` lives outside the web root and is never committed.
