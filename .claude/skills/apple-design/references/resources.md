# Official Apple Design Resources

Official index: https://developer.apple.com/design/resources/

This file is a manifest, not a redistribution of Apple assets. Follow Apple’s terms for each resource. Figma and Sketch libraries remain linked to their official hosts. macOS-only `.dmg` tools are not installable in this Linux workspace.

## Fonts

Official font downloads are listed under Apple Design Resources, including SF Pro and other Apple type families. Review the license before use or redistribution.

https://developer.apple.com/design/resources/#fonts

## SF Symbols

- More than 7,000 symbols in the current Apple tool/catalog.
- Current resource page lists SF Symbols 8 beta and SF Symbols 7.
- The SF Symbols app requires macOS Sonoma or later.
- Symbols have usage restrictions and must not be used in app icons, logos, or trademark-like applications.

Official:
- https://developer.apple.com/sf-symbols/
- https://developer.apple.com/design/human-interface-guidelines/sf-symbols

## Native Apple design tools

The Apple Design page links:
- Icon Composer
- SF Symbols
- Pass Designer
- Reality Composer Pro

These require supported Apple development environments and cannot be installed in this Debian/Linux sandbox. Use a Mac with the supported OS/Xcode version.
