# watchOS Design System

Official: https://developer.apple.com/design/human-interface-guidelines/designing-for-watchos

## Character

- Small wrist display, viewed at close range and often while moving.
- Interactions should be glanceable and typically last less than a minute.
- The related surfaces—complications, notifications, widgets/Smart Stack, Siri/Shortcuts—may be used more than the full app.
- Inputs include touch, swipe/drag, Digital Crown, Action button, voice/shortcuts, and sensor context.

## Principles

- One glance should answer the primary question.
- Prefer one or two gestures for a targeted action.
- Keep navigation hierarchy shallow.
- Use the Digital Crown for vertical scrolling or discrete value/screen changes where appropriate.
- Anticipate relevant, timely needs without becoming noisy or intrusive.
- Treat Always On as a distinct reduced-information state.
- Build an independent watch experience; don’t make the iPhone a mandatory remote for basic tasks.
- Use color and materials as supporting information, not decoration that compromises legibility.

## Target baseline

- Default text: 16 pt
- Minimum custom text: 12 pt
- Default target: 44×44 pt
- Minimum target: 28×28 pt
- Support text enlargement to at least 140%.

## Review checklist

- [ ] Primary information understandable in a glance
- [ ] Primary action within one or two gestures
- [ ] Shallow hierarchy
- [ ] Digital Crown behavior where useful
- [ ] Always On state
- [ ] Complication/notification/Smart Stack strategy
- [ ] Motion-safe use while walking
- [ ] Dynamic Type and VoiceOver
- [ ] No phone-sized information architecture compressed onto the wrist
