# Components, Patterns, Inputs, and Technologies

## Components

Official index: https://developer.apple.com/design/human-interface-guidelines/components

Families:
- Content
- Layout and organization
- Menus and actions
- Navigation and search
- Presentation
- Selection and input
- Status
- System experiences

Default to system components. Customize only when the result preserves platform semantics, focus, keyboard/remote/gaze behavior, accessibility, state communication, and expected dismissal/navigation.

## Patterns

Official index: https://developer.apple.com/design/human-interface-guidelines/patterns

Before creating a bespoke flow, check HIG patterns for onboarding, loading, feedback, data entry, drag/drop, search, modality, multitasking, notifications, accounts, settings, permissions, media, haptics, undo/redo, sharing, full screen, file management, and collaboration.

For each flow define:
- entry and exit
- cancel/back/undo
- loading/empty/error/offline states
- permission denial and recovery
- destructive confirmation
- persistence/restoration
- accessibility announcement and focus destination

## Inputs

Official index: https://developer.apple.com/design/human-interface-guidelines/inputs

| Input | Design implication |
|---|---|
| Touch | Immediate feedback, 1:1 tracking, 44pt targets |
| Keyboard | Complete focus order, shortcuts, command discoverability |
| Mouse/trackpad | Precision, hover feedback, context menus; never hover-only |
| Apple Pencil | Low latency, precision, hover/gesture support, touch alternative |
| Digital Crown | Vertical navigation or value progression with clear feedback |
| Remote/focus | Predictable directional focus and strong focused state |
| Eyes + indirect gesture | Generous separated gaze targets and restrained hover effects |
| Voice/Siri | Clear confirmation, privacy, and visual/manual alternative |
| Game controller | Consistent mappings and platform-standard prompts |
| Sensors/motion | Permission, calibration, privacy, and non-motion fallback |

## Technologies

Official index: https://developer.apple.com/design/human-interface-guidelines/technologies

Technology-specific branding and flows—Apple Pay, Sign in with Apple, HealthKit, HomeKit, CarPlay, Wallet, Siri, AirPlay, AR, SharePlay, Game Center and others—have dedicated rules and often official artwork. Never recreate Apple marks or infer brand rules from screenshots; use the official guidance and assets linked from Apple Design Resources.
